# System Modes — HumanOS

This system operates in clearly defined modes to prevent misuse,
over-interpretation, or unethical deployment.

---

## 1. Education Mode
**Purpose**
- Learning support
- Skill progression
- Task difficulty adaptation

**Allowed Outputs**
- Accuracy
- Latency
- Learning insights
- Growth suggestions

**Explicitly Not**
- Intelligence measurement
- Ability ceilings
- Diagnostic labels

---

## 2. Research / Demo Mode
**Purpose**
- Behavioral pattern observation
- System testing
- Academic or exploratory analysis

**Allowed Outputs**
- Aggregated metrics
- Confidence & uncertainty indicators
- Explainable insights

**Explicitly Not**
- Individual judgment
- Prediction of future behavior

---

## 3. HR / Workplace Exploration Mode
**Purpose**
- Trend exploration
- Training needs assessment
- Process optimization

**Allowed Outputs**
- Aggregate patterns
- Category-level trends
- Confidence-bounded insights

**Explicitly Not**
- Hiring decisions
- Promotion or termination decisions
- Individual risk scoring

---

## 4. Security / Operations Demo Mode
**Purpose**
- Stress-response simulation
- Training scenario evaluation

**Allowed Outputs**
- Performance consistency
- Task engagement patterns

**Explicitly Not**
- Threat prediction
- Intent inference
- Behavioral risk labeling

---

## Global Rule
No mode:
- Diagnoses
- Predicts intent
- Infers psychological traits
- Operates without consent
