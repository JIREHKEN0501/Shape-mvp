1. Support Channels

HumanOS provides three primary support routes:

1.1 Email Support

📧 support@humanostech.com

For general questions, technical issues, or account inquiries.
Response time: within 24 hours

1.2 Admin Dashboard Support (School Partners)

Available only to schools using HumanOS.
Includes:

student export requests

deletion/withdrawal requests

session anomalies

behavior-analytics questions

onboarding support

Response time: within 24–48 hours

1.3 Emergency Channel (High-Severity Issues Only)

Used for:

platform outages

inability to run assessments

broken consent flows

critical child-safety or privacy concerns

Response time: ≤ 6 hours

(Email + dashboard will provide the emergency contact.)

2. Issue Severity Levels
Severity	Description	Expected Response
High	Platform down, data access failure, consent not working	≤ 6 hours
Medium	Specific endpoint issues, export failures, integration errors	≤ 24 hours
Low	General questions, feature requests, feedback	≤ 48 hours

HumanOS ensures all user-impact issues are triaged quickly.

3. Escalation Pathway
Step 1 — Initial Support (Tier 1)

Handled by: Client Success
They review, categorize, and attempt first-level resolution.

Step 2 — Technical Review (Tier 2)

If Tier 1 cannot resolve, the issue is escalated to Engineering.

Examples:

session logs not saving

task catalog issues

data export errors

admin token issues

Response Time: 24–48 hours

Step 3 — Compliance/Security (Tier 3)

Triggered only when:

minors’ data rights are involved

deletion/export complexities exist

potential breach or misconfiguration is suspected

Response Time: 72 hours (max)

4. School-Specific Support

Schools receive:

a dedicated onboarding guide

monthly review calls (optional)

one technical point of contact

priority queue for student-related data rights

5. Parent/Guardian Support

Parents can request:

export

deletion

withdrawal

information about what data HumanOS stores

HumanOS responds within 72 hours of verified requests.

6. Completion of Support Tickets

A ticket is considered resolved when:

response provided

fix applied

export delivered

deletion completed

confirmation sent

All resolutions are logged internally.
