HumanOS Tech — Public Changelog Policy

We maintain a transparent and easy-to-understand changelog for all updates to HumanOS Tech.

1. What We Track

feature updates

bug fixes

performance improvements

dashboard changes

new task categories

security updates

compliance updates (e.g., privacy policy changes)

2. Versioning

We use standard semantic versioning:

MAJOR.MINOR.PATCH


Examples:

new features → MINOR

fixes → PATCH

major changes to scoring or analytics → MAJOR

3. Transparency Commitment

For every release, we publish:

what changed

why it changed

impact on users

whether any action is needed

4. Access

The public changelog is always available at:

/docs/CHANGELOG.md    (included in product)

5. Privacy Note

We never include:

personal data

session data

participant identifiers

internal security details
