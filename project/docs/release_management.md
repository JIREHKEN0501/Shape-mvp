HumanOS Tech — Public Release Transparency Policy

To maintain transparency, HumanOS Tech publishes clear and accessible notes for every update.

1. What We Publish

For every release, we share:

what changed

why it changed

whether the update affects users

if any action is required

version number

We never include personal data.

2. Release Types

We use semantic versioning:

Major: large upgrades or significant feature additions
Minor: new tasks, dashboards, UX updates
Patch: bug fixes and minor improvements
3. Safety Commitment

Before any public release:

the system is tested

dashboards are validated

educational and child-safety features are verified

privacy policies are updated when needed

4. Where Releases Are Published

All release notes are available at:

/docs/CHANGELOG.md
