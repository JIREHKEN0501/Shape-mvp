1. Overview

This Service Level Agreement (“SLA”) outlines the uptime, support, and service expectations for HumanOS Tech’s cognitive-behavioral assessment platform (“Platform”). It applies to all subscribed schools, organizations, and authorized users.

2. Uptime Commitment

HumanOS Tech commits to maintaining a minimum 99.5% monthly uptime, excluding scheduled maintenance windows.

Uptime includes:

Task delivery APIs

Session handling

Dashboard services

Data export APIs

Exclusions:

Scheduled maintenance (announced at least 72 hours in advance)

Internet outages outside HumanOS infrastructure

Customer-side misconfiguration

Force majeure events

3. Maintenance Windows

Planned maintenance occurs during low-traffic periods.

Standard window: Sundays, 02:00–04:00 (UTC)

Emergency patching may occur but will be announced as early as possible.

4. Support Availability

Support hours: 09:00–17:00 WAT, Monday–Friday.

Support channels:

Email: support@humanos.tech

Web portal (coming soon)

Emergency security hotline (for breaches only): security@humanos.tech

Severity Levels & Response Times

Severity	Description	Response Time
Critical (S1)	System down, no workaround	≤ 2 hours
High (S2)	Major feature broken	≤ 6 hours
Medium (S3)	Degraded performance	≤ 24 hours
Low (S4)	UI issues / non-urgent	≤ 3 business days
5. Data Processing & Security

HumanOS adheres to:

NDPR

GDPR

COPPA (when minors are involved)

HumanOS Ethical AI Standards

Security features include:

Encrypted storage (AES-256)

HTTPS/TLS enforcement

Role-based access controls

Audit logging

See: privacy_notice.md, data_subject_rights.md, DPA_template.md.

6. Backup & Recovery

Daily encrypted backups (30-day rotation)

Recovery Time Objective (RTO): < 4 hours

Recovery Point Objective (RPO): < 24 hours

7. Service Credits

If uptime falls below 99.5%, the customer receives:

Uptime Range	Credit
99.5–98%	5% of monthly subscription
98–95%	15%
<95%	30%

Credits apply to the next billing cycle.

8. Termination

Customer may terminate the SLA if HumanOS fails to meet commitments for 3 consecutive months.

9. Changes to This SLA

HumanOS may update this SLA with 30 days' notice.
