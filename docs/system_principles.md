# System Principles

This system is governed by the constraints and commitments
defined in `ETHICS.md`.

These principles describe how ethical boundaries are enforced
in system design, data handling, and user experience

Session Lifecycle & Scope

A session represents a single, bounded interaction between a participant and one task.

A session begins when a task is loaded.

A session ends when results are submitted.

Sessions are immutable once saved.

Sessions are:

Contextual (specific to task, time, and conditions)

Non-diagnostic

Non-permanent representations of behavior

A session does not represent:

A stable trait

A psychological profile

A prediction about future behavior

Sessions must not be aggregated into person-level conclusions without:

Explicit participant consent

A separate analysis pipeline

Clear disclosure of limitations
