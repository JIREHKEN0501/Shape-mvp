
# ADR-002 — Snapshot Governance Before Temporal Governance

## Status

Accepted

---

## Context

As governance evaluators expanded, architectural pressure
emerged around temporal governance semantics.

Questions began surfacing regarding:

- confidence history
- rehabilitation velocity
- authority rebound pacing
- reevaluation persistence
- longitudinal governance analysis
- temporal legitimacy progression

Current evaluators operated primarily on:
- instantaneous runtime state
rather than:
- historical governance trajectories.

Examples included:
- INV-001 restriction precedence
- INV-002 legitimacy inflation
- INV-008 constrained rehabilitation

These evaluators currently interpret governance using
snapshot runtime context only.

---

## Decision

The architecture intentionally prioritizes:

snapshot governance validation

before introducing:

temporal governance infrastructure.

Current runtime governance evaluation therefore remains:
- state-based
- deterministic
- replay-independent
- history-agnostic

until constitutional semantics stabilize further.

Temporal governance concerns were intentionally deferred.

---

## Rationale

Introducing temporal governance semantics too early would
significantly increase architectural complexity through:

- replay systems
- governance persistence
- historical state windows
- recovery velocity analysis
- temporal threshold semantics
- reevaluation cadence logic
- longitudinal telemetry interpretation

At the current maturity stage, snapshot governance
provides sufficient constitutional pressure-testing while
preserving:

- evaluator explainability
- infrastructure simplicity
- deterministic validation behavior
- semantic tractability

---

## Consequences

### Positive

- simplifies evaluator implementation
- improves explainability
- reduces governance ambiguity
- stabilizes constitutional semantics
- accelerates infrastructure iteration

### Negative

- rehabilitation pacing remains approximated
- recovery velocity cannot yet be measured directly
- reevaluation persistence is not yet modeled
- longitudinal legitimacy drift remains untracked

---

## Deferred Concerns

The following governance capabilities were intentionally
deferred:

- temporal replay systems
- confidence history tracking
- rehabilitation velocity analysis
- reevaluation cadence modeling
- persistence-sensitive escalation
- longitudinal governance synthesis
- governance state timelines

These concerns are expected to re-emerge during future
temporal governance expansion phases.

---

## Notes

Current governance evaluators should be interpreted as:

snapshot constitutional approximations

rather than:

fully temporal governance intelligence systems.

This distinction is considered architecturally important
for future governance evolution.
